# Необязательные плагины DeckWeave

`registry.json` — локальный каталог исходников дополнительных пакетов. Сейчас содержит Weather 0.1.0; пакет находится в соседнем репозитории deckweave. Это метаданные, автоматический Marketplace installer ещё не реализован.

Тип `workspace` разрешает путь относительно этого каталога. Текущий development host DeckWeave сканирует `deckweave/plugins`, поэтому погода доступна без копирования. Дистрибутив стороннего Elgato Weather сюда не включается.
